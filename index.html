À propos du projet

Les histoires méritent de rester.

Les Chroniques Shinobi sont pensées comme une galerie communautaire dédiée aux aventures vécues sur le serveur Naruto RP. Un lieu pour partager les images, revoir les événements marquants et garder une trace des histoires construites ensemble.

Le site est public : chacun pourra découvrir les chroniques publiées, même sans faire partie du serveur. Les contributions et les nouvelles catégories pourront être ajoutées progressivement.
